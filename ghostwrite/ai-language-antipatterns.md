# AI Language Anti-Patterns

A blocklist of words, phrases, structures, and habits that make text sound
AI-generated. Use this as a hard filter when ghostwriting in a human voice.

**Rule:** If the voice profile says the user naturally uses one of these patterns,
that's an exception — note it and allow it. Otherwise, these are banned.

---

## 1. Filler Phrases (Hedging / Over-Qualifying)

These add no information. They're throat-clearing before the AI gets to the point.

| Banned phrase | Why it's a tell |
|---|---|
| "It's important to note that" | Nobody talks like this |
| "It's worth mentioning that" | Same energy |
| "It bears noting that" | Academic AI filler |
| "It should be noted that" | Passive voice + filler |
| "It's crucial to understand that" | Inflates trivial points |
| "In today's [landscape/world/era]" | Vague temporal padding |
| "At its core" | Pretends depth, adds nothing |
| "At the end of the day" | Cliche filler |
| "When it comes to" | Throat-clearing |
| "In terms of" | Almost always deletable |
| "From a [X] perspective" | Corporate-speak filler |
| "With that being said" | Use "but" or just say the next thing |
| "Having said that" | Same |
| "That being said" | Same |
| "Let's dive into" / "Let's explore" / "Let's unpack" | Meta-commentary: narrating the writing instead of writing |
| "As you may know" | Condescending filler |
| "Based on the information provided" | Robotic, nobody talks like this |
| "In this section, we will" | Narrating structure |
| "As technology continues to evolve" | Vapid futurism |

## 2. Connector Cliches (Transition Words AI Overuses)

AI uses these to create the illusion of logical flow between unrelated sentences.

**Banned:** Moreover, Furthermore, Additionally, Consequently, Subsequently,
Notably, Importantly, Interestingly, Essentially, Fundamentally, Ultimately,
Indeed, Certainly, Undoubtedly, Arguably

**Also suspect (use sparingly, never to open a sentence):**
However, Nevertheless, Nonetheless, Conversely, Alternatively, Meanwhile

**What to do instead:** Just start the next sentence. If the connection isn't
obvious without a transition word, the problem is the writing, not the transition.

## 3. Enthusiasm Inflation

AI defaults to performative warmth. Real people don't congratulate you for asking.

| Banned | Why |
|---|---|
| "Absolutely!" | Performative agreement |
| "Great question!" | Patronizing |
| "That's a great point!" | Same |
| "I'd be happy to help" | Nobody asked if you're happy |
| "I'd love to" | Fake warmth |
| "Excellent choice!" | Sycophantic |
| "What a [great/wonderful/fantastic] [idea/approach]!" | AI cheerleading |
| "I'm excited to" / "I'm thrilled to" | Nobody is thrilled to write a cover letter |

## 4. Structure Tics

AI defaults to over-organized output: numbered lists, headers, bullet points.

| Pattern | Problem |
|---|---|
| Bullet lists for everything | Humans write paragraphs when explaining |
| "Here's what you need to know:" | Sets up a list nobody asked for |
| "Here's the thing:" | AI's attempt at conversational |
| "Let's break this down:" | Then proceeds to over-structure |
| "There are [N] key [things/aspects/considerations]:" | Enumeration fetish |
| Colon before every list | Humans often just... continue the sentence |
| Bold key phrases mid-paragraph | AI highlighting tic |

## 5. Vocabulary Tells

Words AI uses 10-100x more than humans. If you see these, rewrite.

### Tier 1 — Dead Giveaways
delve, landscape, tapestry, multifaceted, myriad, paradigm, synergy,
holistic, nuanced, robust, leverage (as verb), utilize, facilitate,
encompasses, underscores, underpin, pivotal, transformative, groundbreaking,
elucidate, embark, endeavor, testament ("a testament to"), juxtapose,
kaleidoscope, symphony (metaphorical), plethora, catalyze

### Tier 2 — Heavily Overused
streamline, optimize, enhance, empower, foster, cultivate, navigate (metaphorical),
unlock, harness, spearhead, craft (as verb for writing), curate, elevate,
comprehensive, cutting-edge, seamless, innovative, dynamic, impactful,
invaluable, insightful, noteworthy, overarching, meticulous, intricate

### Tier 3 — Suspect in Clusters
realm, sphere, domain, arena, journey, narrative, framework, ecosystem,
intersection, cornerstone, linchpin, catalyst, deep dive, unpack,
double-edged sword, game-changer, no-brainer, low-hanging fruit,
galvanize, bolster, garner, interplay, enduring, vibrant

### Tier 4 — AI-Inflated Verbs
Verbs AI substitutes to avoid simple "is/has/shows":

| AI Verb | Just say |
|---|---|
| "serves as" | is |
| "stands as" | is |
| "represents" | is |
| "boasts" (meaning "has") | has |
| "features" | has |
| "exemplifies" | shows |
| "underscores" | shows |
| "highlights" | shows |
| "showcasing" | showing |
| "aligns with" | matches, fits |

**Replacement strategy:** Use the simplest word. "Utilize" → "use".
"Leverage" → "use". "Facilitate" → "help". "Comprehensive" → "full" or "complete".
"Navigate challenges" → "deal with problems". "Craft a narrative" → "write".
"Serves as" → "is". "Boasts" → "has". "Showcasing" → "showing".

## 6. Punctuation Habits

| Pattern | Problem |
|---|---|
| Em dash overuse (—) | AI's favorite connector, 3-5x per paragraph |
| Semicolons in casual writing | Humans rarely use semicolons outside formal prose |
| Exclamation marks on non-exciting things | "Here's your summary!" |
| Colon + list on every enumeration | Human speech flows without colons |
| Oxford comma (context-dependent) | Not inherently AI, but check the user's habit |
| Ellipsis abuse (...) | Some AI models trail off constantly |

## 7. Sentence Patterns

| Pattern | Example | Problem |
|---|---|---|
| Mirror-back | "You asked about X. X is..." | AI restates the question before answering |
| "Let me" opener | "Let me explain how..." | AI's performative helpfulness |
| "I" sentence starts | "I think... I believe... I would..." | AI cycles through I-statements |
| The pivot | "While X, Y" every other sentence | Overuse of contrastive structure |
| Triple structure | "X, Y, and Z" in every sentence | AI loves triads |
| Parallel construction | "Not just X, but Y" | Fine occasionally, AI does it constantly |
| The thesis statement | Opening sentence that summarizes everything | AI frontloads conclusions |

## 8. Sign-Off Patterns

These scream "AI wrote this." Never use them.

- "Let me know if you have any questions!"
- "Hope this helps!"
- "Feel free to reach out"
- "Feel free to [anything]"
- "Don't hesitate to [anything]"
- "I'm here if you need anything else"
- "Happy to discuss further"
- "Looking forward to hearing from you"
- "Best regards" (in casual contexts)
- "I hope this provides clarity"
- "I trust this addresses your question"

## 9. Hedging Patterns

AI hedges to avoid being wrong. Humans commit to positions.

| Banned | Replace with |
|---|---|
| "may or may not" | Pick one |
| "it depends on your specific needs" | Say what it depends on |
| "there are pros and cons to both" | Name them or pick a side |
| "it's a matter of personal preference" | Cop-out |
| "results may vary" | Disclaimer, not writing |
| "generally speaking" | Just speak |
| "in most cases" | Be specific or remove |
| "it's worth considering" | Just state the consideration |
| "one could argue that" | Then argue it |
| "some might say" | Who? Or just say it |

## 10. Structural Anti-Patterns

| Pattern | Problem |
|---|---|
| Summary paragraph at end | AI recaps what it just said |
| "In conclusion" / "To summarize" / "In summary" | Same — just stop writing |
| Repetition of the question in the first line | AI restates before answering |
| "As [mentioned/discussed/noted] [earlier/above]" | Self-referential filler |
| Disclaimer paragraphs | "This is just my perspective..." |
| Equal weight to all points | AI gives everything the same emphasis |
| Perfect grammar throughout | Real humans make small errors, use fragments |

## 11. Cadence Tells

| Pattern | Problem |
|---|---|
| Every sentence roughly the same length | AI defaults to 15-25 word sentences |
| No fragments | Real speech has fragments everywhere |
| No one-word sentences | Sometimes "No." is the right answer |
| Perfectly alternating short/long | AI's idea of "varied" sentence length |
| Complete thoughts always | Humans trail off, restart, leave things implied |

## 12. Content-Level Tells

These are harder to catch because they're about what's missing, not what's present.

| Pattern | Problem |
|---|---|
| No specifics | Generic claims without data, names, or anecdotes |
| False depth | Restates the problem in fancier words, lists obvious things |
| Promotional register | "boasts a...", "nestled in the heart of", "rich heritage" |
| No personal markers | No real opinion, humor, sarcasm, or personality |
| Suspiciously even tone | Same emotional temperature across the whole piece |
| "Challenges and Future" formula | Rigid sections predicting what might happen next |
| Elegant variation | Different synonym for the same thing every sentence |

## Quick Smell Test

Read the text aloud and ask:

1. Would you be embarrassed if someone asked whether AI wrote it?
2. Is anything specific, surprising, or personal?
3. Could you swap the topic and the text would still work? (If yes, it's slop.)
4. Does every paragraph follow the same template?
5. Are there more than two em dashes on the page?
6. Do all sentences stay in the same length band, or is there real burstiness?
7. Is there a single concrete example, named source, or personal anecdote?

Human writing surprises. Slop never does.

## Usage in Ghostwriting

1. **Hard filter:** Before outputting any text, scan for Tier 1 vocabulary tells,
   filler phrases, enthusiasm inflation, and sign-off patterns. These are always wrong.
2. **Soft filter:** Tier 2-3 vocabulary, hedging, and structural patterns are
   contextual. Check against the user's voice profile for exceptions.
3. **Cadence check:** After drafting, read the output aloud. If it sounds like
   a well-trained assistant, it's too smooth. Add fragments, vary length, drop
   transitions.
4. **The newspaper test:** Would a human editor flag this as AI-generated? If yes,
   rewrite the flagged sections.
